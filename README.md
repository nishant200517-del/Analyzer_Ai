# Analyzer_Ai
Here, I tried to make a Analyzer AI is a Generative AI-powered analytics assistant that can process and interpret raw files (CSV, TXT, JSON, Logs, Excel, etc.) and generate actionable insights in a conversational and visual manner. I have used free models to built it.
I have used Hugging Face Models ("Qwen/Qwen2.5-1.5B-Instruct") to generate actionable insights in a conversational and visual manner.
